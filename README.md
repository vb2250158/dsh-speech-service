# 语音服务

独立的 DSH 语音增强插件，在官方语音输入上增加静音收尾、自动发送和自动朗读。无需修改官方源码。

启用官方语音输入并准备识别模型后，再启用本插件。在本插件设置中勾选「增强输入框语音」，普通输入框会显示话筒与录音波形。开始说话后，音量持续低于配置阈值达到 1000 毫秒（默认值），就结束录音并调用官方语音识别接口。全程无声音不会提前结束，最长录音时间沿用官方服务限制。

「转写后自动发送」仅在转写成功插入原草稿后提交。录制期间修改草稿造成冲突时，保留转写文字供手动插入；空结果、取消、切换会话和权限失败不会发送。自动朗读只播放启用后的新回复正文，跳过历史、推理、工具调用与中断回复；离开会话、隐藏页面或关闭开关时停止。

识别模型、语言与准备进度仍在官方语音输入设置中。本插件只存储增强偏好。朗读需要启用 dsh-rabiroute-agent，并在 Rabi 配置可用的默认 TTS；通过现有 `/rabiroute/speech` 接口请求音频，不创建新的识别或合成引擎。

## 逐步退役

官方增加对应能力后，逐项关闭「静音后自动结束录音」「转写后自动发送」「自动朗读回复」。关闭「增强输入框语音」会撤销公开输入插槽替换、立即恢复官方控件；朗读仍可独立启用。官方全部覆盖后可卸载本插件。不会根据版本号猜测官方能力，也不会偷偷修改官方配置。

公开接入点：`conversation.input.activity`（优先级 -100 的替换）、`plugins.bundle.config`（本插件设置）与 `conversation.session.header.actions`（当前会话朗读）。插件卸载撤销注册并等待录音、资源与远端观察释放。

## 开发

`npm install --ignore-scripts --legacy-peer-deps`，然后 `npm run build`。源码不依赖官方私有组件；维护的录音界面基于 MIT 代码，来源见 THIRD_PARTY_NOTICES.md。DSH 当前支持范围为 0.2.1-alpha.1 至 0.3.0 之前；发布包含 lib 产物，不要求安装端构建。

`npm test` 验证回复筛选。DSH 配套客户端行为和浏览器测试需要官方开发工作区，用 tests 中的运行脚本执行。它们测试静音、草稿冲突、取消、标准 ConfigForm 持久化、官方控件恢复及真实浏览器音频播放。
